## 📦 Como rodar localmente

```bash
git clone https://github.com/KaioHSG/kaiohsg.github.io.git
cd kaiohsg.github.io
# Só abrir o index.html no navegador!
```

Não tem build, não tem bundler, não tem framework. É só **HTML puro** (e um pouco de CSS).
